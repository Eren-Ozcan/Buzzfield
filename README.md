# Buzzfield: Bloom Idle

A portrait idle game by Yilk Games: bees carry nectar from flowers to the hive, honey buys
more and better bees, and the grey garden blooms into colour as it is worked.

Built with Unity 6.3 LTS (URP). Work in progress.

## Getting started

1. Open the project with Unity 6000.3.25f1.
2. Run **Buzzfield > Create Default Data** (imports TextMeshPro resources, creates data, prefabs, materials).
3. Run **Buzzfield > Build Greybox Scene**, then open `Assets/_Project/Scenes/Main.unity` and press Play.

EditMode tests: **Window > General > Test Runner > EditMode > Run All**.
